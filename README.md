# Enterprise IT Security Framework — Interactive Build Guide

A single-file, self-contained interactive guide to a dependency-led, seven-stage enterprise IT security framework: 95 stage actions, 84 baseline controls across 15 domains, 10 cross-cutting security disciplines, a framework crosswalk (ISO 27001, NIST CSF 2.0, NIST 800-53, CIS v8, SOC 2, and more), a 100-item illustrative tool catalogue, and fillable practice record templates.

Open `index.html` directly in a browser, or view it published via GitHub Pages.

**This is a personal consolidated draft for owner review and local adoption** — it is not organisational policy, a certification, or legal advice. All worked examples (including the synthetic CUSTOMER_A/CUSTOMER_B worked service) are synthetic; no control or test described in the guide has actually been executed. Tool names throughout are illustrative examples only, not purchasing recommendations.
